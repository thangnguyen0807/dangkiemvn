# Tra cứu đăng kiểm xe dành cho Home Assistant

## Installation

### HACS
1. Thêm kho lưu trữ này làm kho lưu trữ HACS tùy chỉnh (Tích hợp).
2. Cài đặt **Đăng kiểm Việt Nam** .
3. Khởi động lại Home Assistant.
4. Vào **Cài đặt → Thiết bị và dịch vụ → Thêm tích hợp → Đăng kiểm Việt Nam**.
5. Nhập **Biển số, 6 số cuối của số khung xe của bạn vào** .
